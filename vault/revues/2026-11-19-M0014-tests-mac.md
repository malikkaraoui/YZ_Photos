## Pourquoi le Mac a échoué (les essais, dans l'ordre)

1. `-destination 'platform=macOS,arch=arm64,variant=Designed for [iPad,iPhone]'` : refusée par xcodebuild, `unreadable input 'iPhone]'` (la virgule coupe la valeur). Le mandat donnait une destination non parseable.
2. `-destination 'id=00008103-001545AE1439001E'` : compilation OK, puis refus de signature : le profil « iOS Team Provisioning Profile » ne couvre pas le Mac.
3. Idem avec `CODE_SIGNING_ALLOWED=NO` : installation refusée, `No code signature found`.
4. Idem avec `CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=YES` : refus, les entitlements exigent un certificat de développement.
5. Repli iPhone sans équipe : `Signing for "YZPhotosTests" requires a development team`.
6. Repli iPhone avec `DEVELOPMENT_TEAM=UPES5479T5` (équipe déjà présente dans le projet pour le target `YZPhotos`) : vert.

Constat pré-existant : le target `YZPhotosTests` n'a pas de `DEVELOPMENT_TEAM` dans le `project.pbxproj` de `main` non plus. Ce n'est pas un effet de M0013. Correctif de projet non fait (hors mandat).
